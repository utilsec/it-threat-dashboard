# it-threat-dashboard

Static publish of Mike Holcomb's **IT cybersecurity threat dashboard**, served via
GitHub Pages at `https://utilsec.github.io/it-threat-dashboard/`.

- `index.html` — the dashboard (regenerated upstream; do not hand-edit).
- `feed.json` / `rss.xml` — machine-readable feeds (see the project's
  `FEED-INTEGRATION.md`).
- `publish.bat` — stages, commits, and pushes updates (wrapper around the project's
  `update-dashboard.ps1`).

In partnership with Mike Holcomb & UtilSec. Editorial summaries — verify against each
item's linked primary source before acting.
