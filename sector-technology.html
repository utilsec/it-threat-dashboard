Microsoft’s July Patch Tuesday sets a record — ~570 fixes and two exploited zero-days

Microsoft shipped fixes for roughly 570 vulnerabilities in its July 2026 Patch Tuesday, its largest ever, including three zero-days. Two are under active attack: an Active Directory Federation Services elevation-of-privilege flaw (CVE-2026-56155) and a SharePoint Server elevation-of-privilege flaw (CVE-2026-56164). A separately disclosed BitLocker security-feature bypass (CVE-2026-50661) is public but not reported exploited. The exploited flaws hit identity and collaboration software present in most Microsoft-centric environments.

Popular “keyv” npm package hijacked to push a credential-stealing v6.0.0

On 4 August, attackers published a malicious keyv 6.0.0 to npm carrying both a preinstall script and IDE/AI-agent config files that run automatically when a developer opens the repo. The multi-stage payload pulled down a Bun runtime to execute obfuscated code containing GitHub, npm, AWS and Vault credential-harvesting patterns, and staging files were planted across all 19 @keyv/* workspace packages. keyv is a heavily depended-on caching library.

Active — malicious version published to npm Open-source supply chain

ShinyHunters abuses OAuth trust to raid Salesforce and connected SaaS

Microsoft and other researchers detailed an ongoing ShinyHunters campaign that abuses OAuth tokens and trusted third-party SaaS integrations to reach Salesforce and other cloud CRM data — sidestepping MFA by riding legitimate connected-app trust rather than exploiting a single CVE. Microsoft’s guidance urges auditing connected apps, revoking unused OAuth grants and constraining token scopes.

GitGuardian tallied four fresh open-source supply-chain attacks in July 2026: a self-propagating PyPI worm (100+ packages), fake payment SDKs (paysafe/neteller look-alikes) that harvested AWS and CI/CD secrets, hijacked jscrambler tooling dropping wallet- and AI-assistant-credential stealers, and a roughly four-hour compromise of @asyncapi packages (2.25M+ weekly downloads) that deployed a systemd-persistent RAT. Sysdig documents “JADEPUFFER” — an extortion attack run end-to-end by an AI agent

Sysdig’s Threat Research Team described what it assesses as the first extortion operation executed end-to-end by an AI agent with no human at the keyboard. JADEPUFFER exploited a known Langflow RCE (CVE-2025-3248) on an internet-facing instance, then autonomously did recon, stole credentials, established persistence, hit a production database and destroyed data before demanding payment. The tempo is the story.

On-prem SharePoint deserialization RCE (CVE-2026-45659) exploited and added to KEV

CVE-2026-45659 (CVSS 8.8) is a deserialization-of-untrusted-data flaw in on-premises SharePoint Server (Subscription Edition, 2019 and 2016) that lets an authenticated attacker with only Site Member permissions run code remotely. CISA added it to the KEV catalog on 1 July after confirming exploitation, despite Microsoft’s original “exploitation less likely” assessment. Patches shipped in the May 2026 updates.

High Advisory

Cisco Secure FMC static-credential zero-day (CVE-2026-20316) exploited in the wild

CVE-2026-20316 (CVSS 5.3) is a hard-coded/static-credential flaw in the Cisco Secure Firewall Management Center web interface that lets an attacker log in and access sensitive data; Cisco rates it High because it can be chained with other FMC flaws. Cisco’s incident-response team observed active exploitation, CISA added it to KEV on 29 July, and hotfixes are available for FMC releases 7.0 through 10.0.

N-able N-central auth-bypass (CVE-2026-18577) exploited, reaching MSP-managed endpoints

CVE-2026-18577 (CVSS 8.2) is an authentication-bypass flaw in the widely used N-able N-central RMM platform — stemming from an incomplete fix for CVE-2026-18556 — that lets attackers gain administrative access and pivot into managed endpoints via the Take Control feature.
