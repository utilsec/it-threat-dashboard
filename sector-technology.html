VMware vCenter flaw under mass exploitation reaches 361 victims in 47 countries — now in CISA KEV with a 21 August deadline

CVE-2026-59310 (CVSS 9.8) is a directory-traversal flaw in vCenter Server’s syslog service that gives an unauthenticated attacker code execution on the virtualization management plane. Worth keeping in proportion, though: 361 victim IPs is a serious, geographically broad campaign, not a compromise of a large share of the world’s IT environments.

Microsoft has no patch for ShieldBreak — public exploit code turns any Defender-protected Windows host into a SYSTEM escalation

A researcher operating as “Nightmare Eclipse” published working proof-of-concept code for CVE-2026-69414 on 17 August, and Microsoft has so far confirmed only that it is “working to provide a high quality security update.” The flaw sits in Defender’s Malware Protection Engine and escalates a local foothold to SYSTEM. The researcher reports the PoC succeeding at a 100% rate against fully patched systems; that success claim is the researcher’s, not independently confirmed in the reporting reviewed, but the code itself is public and the vulnerability is unpatched. Affected builds span Windows 10, Windows 11 including 25H2 and Canary, Windows Server 2025 and other Server editions — the precondition is simply that Defender is enabled. No CVSS score has been published, and there is no confirmed in-the-wild exploitation. For technology firms the exposure is structural rather than exotic: Defender is the default enforcing AV on Windows developer workstations, CI runners and jump hosts, and it runs with exactly the privilege an attacker wants. A local-only bug is normally second-tier, but this sector supplies the missing half constantly — a Teams helpdesk lure or a poisoned package import gets code running as the user, and ShieldBreak converts that foothold into SYSTEM on the machine holding signing keys and cloud credentials.

Fourteen npm packages launch the RedC2 4.0 backdoor on import rather than install — which is why the ecosystem’s standard defence misses them

The packages — streak-metrics-math, kit-map-vim, streak-map-cache, streak-map-kit, map-streak-kit, streak-cache-map, streak-calc-metrics, streak-calc-math, streak-math-abz, streak-metricsaz, streak-math-metrics, streak-metricazbd, streak-metricsazb and streak-kit-map, at versions 1.0.0 and 1.0.1 — each bundle a binary that is launched detached the moment application code imports the module. There is no install hook, and that is the detail worth dwelling on: --ignore-scripts, postinstall-blocking CI policy and install-time script auditing, which is where most organisations have concentrated their npm defences since 2024, do nothing against execution that happens at require time. It ships with “Red Agent,” an AI assistant that drives post-exploitation from natural-language instructions. It has been sold since June 2026 for $99.99 by a seller using the handle “MarlboroMan” through a storefront called Red Offsec. For technology organisations the combination is unusually bad. Node build and test runners are Linux hosts that hold SSH keys, registry tokens and cloud credentials, and RedC2’s feature set — key theft plus SOCKS5 — is a lateral-movement kit aimed squarely at that host class. The $99.99 price removes any skill floor: this is commodity tooling, and the AI operator module lowers the bar again for whoever buys it.

Medium Research

A Spectre-class side channel crosses the Cloudflare Workers tenant boundary — too slow to steal a database, fast enough to steal the token that opens one

The mechanism is one Worker reading memory belonging to another Worker co-located on the same host, and the measured rate is roughly 12 bits per second. Researchers showed that this is sufficient to recover a JSON Web Token from the neighbouring tenant. The distinction carries the whole finding: a channel that could never move bulk customer data can still move the small, high-value, directly replayable credential that unlocks it, and bandwidth is therefore the wrong lens for judging severity here. Several things are not established and should not be assumed. No CVE has been assigned in the reporting reviewed. No CVSS score, no Cloudflare patch status and no vendor mitigation guidance appear in the coverage. There is no evidence of exploitation in the wild — this is a research demonstration, not an incident. The consequence for technology organisations is architectural rather than operational. Workers and comparable V8-isolate platforms earn their cost and cold-start advantages precisely by packing many tenants into a single process boundary, in place of the per-tenant VM or container isolation that other serverless models rely on. That trade assumes software-level isolation holds, and a transient-execution side channel is exactly the bug class that assumption cannot absorb, because the leak occurs below the layer the isolation is enforced at. Anything a Worker keeps resident — session tokens, API keys, signing material for downstream services — should now be treated as sitting behind a best-effort boundary rather than a hard one.

The stolen material — browser-stored credentials on a build host — is the same currency the npm RedC2 campaign is after this week, and it is why the exposure to audit is the build identity, not the shipped binary.

GitLab ships an emergency patch for a critical code-injection flaw and a zero-click GraphQL project-deletion bug

GitLab released an out-of-band security update on 18 August 2026 covering two serious issues. The first is a critical code-injection vulnerability in GitLab itself. Ray code-injection flaw added to CISA KEV — a malicious web page can reach a developer’s local cluster

CISA added CVE-2025-62593, a code-injection flaw in the Ray distributed-computing framework, to its Known Exploited Vulnerabilities catalog on 17 August 2026 with a CVSS score of 9.4 and a 20 August federal remediation deadline. Ray ships with no authentication on critical endpoints by design, on the assumption that clusters run on trusted networks. That assumption breaks in a specific and uncomfortable way: a developer who merely visits a malicious web page or loads a malicious ad can have DNS rebinding used to reach the Ray instance running on their own machine or local network, and execute code against it. Ray is widely used for distributed training and inference, so the compromised environment usually holds model artifacts, training data and cloud credentials. The issue is fixed in Ray 2.52.0.

CISA and FBI refresh the Medusa advisory: 500+ victims and exploits weaponised within about 24 hours

CISA and the FBI updated joint #StopRansomware advisory AA25-071A on 18 August 2026. The cumulative Medusa victim count passed 500 as of April 2026, up from roughly 300 in March 2025 — about 200 new victims in a year across healthcare, critical manufacturing, the defense industrial base, government facilities, financial services and the IT sector itself. The finding that should reshape patching policy is the timeline: the agencies report Medusa weaponising newly disclosed vulnerabilities within roughly 24 hours, and in some cases using exploits up to a week before public disclosure, because the operation buys exploits rather than developing them. For technology and SaaS providers that undercuts the common assumption that a 72-hour or seven-day emergency patch window is aggressive; against this actor it is not, and pre-disclosure exploitation means patch cadence alone cannot be the whole control. Detection and segmentation have to carry the interval the patch cannot cover.
