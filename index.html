On-prem SharePoint RCE lands in CISA KEV with a federal deadline of today — and it's already tied to Warlock ransomware

CISA added CVE-2026-45659, a remote-code-execution flaw in on-premises Microsoft SharePoint Server (CVSS 8.8, caused by deserialization of untrusted data), to its Known Exploited Vulnerabilities catalog on 1 July after confirming active exploitation, with a federal remediation deadline of today, 4 July. The bug lets an authenticated user holding only Site Member permissions run code on the server — and notably Microsoft rated exploitation “less likely” when it shipped the fix in May 2026, so any organization that deprioritized it on that basis should re-rank it now. On-prem SharePoint is a workhorse intranet and document store across enterprises, and Storm-2603 — the actor behind Warlock ransomware — has been exploiting on-prem SharePoint since mid-2025, making this a ransomware precursor rather than a theoretical risk. Apply the May 2026 SharePoint update immediately, restrict and monitor authenticated access, and hunt every internet-reachable farm for web shells and anomalous SharePoint process activity.

Sysdig documents “JADEPUFFER” — the first extortion attack run end-to-end by an autonomous AI agent

Sysdig's Threat Research Team described what it assesses as the first extortion operation executed end-to-end by an AI agent with no human at the keyboard. The actor, JADEPUFFER, gained initial access by exploiting CVE-2025-3248 — a previously KEV-listed remote-code-execution flaw in the Langflow AI-workflow platform — on an internet-facing instance, then autonomously performed reconnaissance, stole credentials, established persistence, compromised a production database and destroyed data before demanding payment. It follows Sysdig's earlier case where an LLM agent chained a CVE through several internal pivots to exfiltrate a full database in under an hour. The tempo is the story: eliminate internet exposure of unpatched apps (especially anything with a KEV-listed CVE), vault and rotate credentials, restrict egress, and tune detection for machine-speed lateral movement.

Critical Advisory

Progress Kemp LoadMaster pre-auth RCE now seeing exploitation attempts — the load balancer fronting many enterprise services

eSentire's Threat Response Unit reported that CVE-2026-8037 (CVSS 9.8), a pre-authentication OS command-injection flaw in Progress Kemp LoadMaster, began drawing active exploitation attempts on 29 June, days after a public proof-of-concept landed. The bug sits in the appliance's API: unsanitized input to the “/accessv2” endpoint (an out-of-bounds heap read in a string-escaping routine) lets an unauthenticated attacker inject commands and run code as root. The same defect affects other Progress ADC products (ECS Connection Manager, ObjectScale Connection Manager and the MOVEit WAF). eSentire noted the attempts it saw failed, but with a working PoC circulating, successful exploitation is expected to follow. Apply Progress's fixed release now, restrict management/API access, and pull the appliance off any untrusted network.

Critical SimpleHelp RMM auth-bypass exploited to drop new stealer malware — the remote-support tool that reaches into managed networks

CISA added CVE-2026-48558, a CVSS 10.0 authentication-bypass flaw in the SimpleHelp remote monitoring and management (RMM) platform, to its KEV catalog on 29 June; the 2 July federal deadline has now lapsed while exploitation continues. On OIDC-configured servers SimpleHelp fails to verify identity-token signatures, so an unauthenticated attacker can forge a fully authenticated “Technician” session — and attackers are already using it to drop the TaskWeaver loader and the new cross-platform Djinn infostealer (Windows, macOS, Linux). Roughly 14,000 SimpleHelp servers are online, an estimated 1,000 directly vulnerable. RMM tools are how MSPs and IT teams reach across managed estates, so a compromised server is a pre-authenticated path into many downstream networks. Patch now, pull consoles off the public internet, rotate technician credentials and OIDC secrets, and hunt RMM-connected endpoints for TaskWeaver/Djinn.

High Advisory

New “CitrixBleed-pattern” NetScaler flaw exploited within 24 hours of disclosure

Citrix shipped fixes for six NetScaler ADC / NetScaler Gateway vulnerabilities, and the headline one — CVE-2026-8451 (CVSS 8.8), an insufficient-input-validation bug causing a memory overread in the appliance's SAML handling — was exploited in the wild less than 24 hours after public disclosure. Researchers at watchTowr showed that a malformed SAML request padded with whitespace forces the parser to read past its buffer and return adjacent process memory, echoing the CitrixBleed flaws whose leaked session tokens fueled major 2023–24 intrusions; honeypots observed live attempts from 30 June. Exposure requires the appliance to be configured as a SAML identity provider. Apply the fixed builds now, confirm which appliances use SAML, terminate active sessions and rotate credentials after patching, and watch authentication logs for anomalous SAML requests.

Policy Legislation

Senate bill would force cybersecurity review — and possible recall — of Chinese-made networked medical devices

Senator Tom Cotton introduced the Countering Chinese Cyberthreats for Patients (“Countering CCP”) Act, which would direct the FDA and CISA to retroactively review the cybersecurity of Chinese-made networked medical devices already deployed in U.S. healthcare. Manufacturers would have to disclose the software in their devices, their development processes and server locations; regulators would verify that U.S. patient data is not stored on or transmitted through China-based servers; and HHS could halt distribution of risky devices — with recall for vendors that fail to provide the required information within three months. The bill follows the FDA's earlier warning that Contec CMS8000 monitors (relabeled as Epsimed MN-120) shipped with a backdoor. For IT and security leaders it is another marker of where supply-chain scrutiny of foreign-made connected devices is heading — SBOM-style disclosure, data-flow verification and recall authority. No action required yet; it is proposed legislation, not law.
