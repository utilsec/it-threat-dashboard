For legal aid practices the update changes two things: their own lawyers’ names are now in the confirmed data, and the affected client population reaches back to files closed decades ago.

Arctic Wolf: fake “IT help desk” chats over Microsoft Teams, sent straight after an inbox flood, get from first contact to a running payload in under 15 minutes — more than 400 incidents

Arctic Wolf Labs reported on 26 October that it has seen more than 400 incidents in which attackers message employees through Microsoft Teams external chat while posing as IT support. The pattern starts with a mail-bomb: the target’s inbox fills with hundreds of newsletter and subscription confirmations within minutes, and a Teams message from “IT support” follows, offering to fix the problem. The attackers use Microsoft 365 tenants with help-desk-style names; in 30–40% of the cases analysed these sat on default onmicrosoft.com domains, which need no verification and take minutes to set up, and Arctic Wolf sees a shift towards paid domains. Once a user engages, Quick Assist is the most common way in, with AnyDesk, ScreenConnect, TeamViewer, Atera and other remote tools also used, and customer-reported chains reached payload execution in under 15 minutes. In one case a PowerShell command pulled an installer from Azure Blob Storage that ran a Python implant to map Active Directory users and computers. Arctic Wolf attributes the activity to no single actor and names no sectors; it notes that earlier campaigns using the same method were linked to Black Basta, Cactus, 3AM and Chaos ransomware. No vulnerability is involved. Law firms suit the lure: busy fee-earners, an expectation that IT fixes things remotely, and the same fake-help-desk approach the Silent Ransom Group uses by phone, covered elsewhere on this page (editorial assessment).

Greenspoon Marder says the law takes effect on 1 January 2027; the State Bar of California is separately developing its own rule changes. The confidentiality clause is a security requirement in all but name: it makes the question of which AI tools can see client data, and who else can, a statutory duty for California practitioners (editorial assessment).
